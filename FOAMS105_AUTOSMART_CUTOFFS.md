# FOAMS 1.0.5 AutoSmart cutoff suggestions

This stage reproduces the bounded default range suggestions from pinned
`defaultbinrange.m`. It returns transparent transition traces and inclusive
per-group ranges. It does not apply those ranges, concatenate distributions,
or replace the existing manual nesting API.

## Public API

Construct one frozen `Foams105CutoffGroupInput` per magnification group in
strictly ascending calibration scale, then call:

```python
suggest_foams105_cutoffs(bin_labels_mm, groups)
```

The result retains validated labels, ordered group IDs/scales/densities,
positive-overlap indices, separately computed signed log differences,
one-sided candidates, exact ties, selected transition indices, and inclusive
label ranges. Exact-zero differences are excluded; equal positive/negative
magnitudes select the negative value; repeated selected values use their last
original row.

`Foams105CutoffDomainError` exposes a stable `code` and immutable `context` for
undefined or unusable suggestions, including no positive overlap, all-equal
log differences, a final-row transition, empty single-group support, and a
reversed proposed range. No interpolation, fallback, reordering, smoothing,
or scientific repair is performed.

## Validation boundary

This suggestion profile accepts one to four groups and one to 45 finite,
positive, strictly increasing labels. That grid restriction is local to this
API and does not alter existing size-class or converter behavior. Returned
ranges are defaults; callers may still choose manual ranges.

The bundled seven-case fixture is hand-designed from documented source
behavior, not generated by MATLAB. Actual source selection/concatenation,
vesicularity, normalization, summaries, remaining shape properties, UI, and
original-equivalent exports remain outside this stage.

Run the headless report with:

```bash
python -m main.examples.foams105_autosmart_cutoffs
```
